# Programação Web II
## Objetivo
  Repositório pessoal dedicado à disciplina Programação Web II. Será usado principalmente para entregas de atividades
  
## Organização
  As atividades da disciplina estarão em uma pasta dedicada, serão organizadas em subpastas de acordo com a forma que as atividades são apresentadas (ex: lista 1 será encontrada em <code>atividades/lista-1</code>) e as respostas estarão presentes em arquivos .md ou .js
